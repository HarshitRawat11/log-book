C · G1 — the cardio session ~35 min

The only task that can genuinely fail and create work.

  1. Configure to about 30 min — e.g. 6 × 4:00 work / 1:00 break.

  3. Note the wall-clock time the instant you tap Start. Without it, drift cannot be computed and the session has to be run again.
  4. Train. Hands off the screen.
  5. Midway, background the app once for about a minute, then return.
  6. At the final cue, note the time. Elapsed minus planned = drift, must be < 2s.
  7. Check the logged round count.
