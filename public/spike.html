Cardio audio spike

Answers one question: with the screen off, do pre-scheduled cues still sound? Run each mode once. Takes about 80 seconds each.

How to run

  1. Set the volume to what you would use in the gym.
  2. Pick a mode, tap Start.
  3. Immediately press the power button to lock the screen.
  4. Listen. Cue 1 is one beep, cue 2 is two beeps, up to cue 6 at 60 s. Count which ones you actually hear.
  5. A long low tone marks the end. Unlock and read the numbers below.
  6. For the 35-minute run the cues are 5 minutes apart, so cue 1 lands at 5 min and cue 6 at 30. You do not need to watch it.
